# Руководство по использованию логотипа Ampleev.com

## Файлы логотипа

Все варианты логотипа находятся в `/blog/public/assets/img/` и могут быть использованы в Blade шаблонах.

---

## Варианты логотипа и рекомендации по использованию

### 1. **logo-full.svg** (320×80px)
**Где использовать:**
- Главная страница сайта (hero-секция)
- Верхний хедер на десктопных версиях
- Футер сайта
- Презентации и документы
- Email-подписи

**Когда использовать:**
- Когда есть достаточно места по горизонтали (от 320px)
- На светлом фоне
- Когда нужна максимальная узнаваемость бренда

**Пример использования:**
```blade
<img src="/assets/img/logo-full.svg" alt="Ampleev.com" class="logo-full">
```

### 2. **logo-compact.svg** (240×60px)
**Где использовать:**
- Мобильная версия хедера
- Боковые панели (sidebar)
- Навигационное меню
- Карточки товаров/услуг

**Когда использовать:**
- На экранах с ограниченным пространством
- В навигации на планшетах
- Когда нужна компактная версия с текстом

**Пример использования:**
```blade
<img src="/assets/img/logo-compact.svg" alt="Ampleev.com" class="logo-compact">
```

### 3. **logo-icon.svg** (60×60px)
**Где использовать:**
- Аватары в социальных сетях
- Водяные знаки
- Кнопка "На главную" в мобильном меню
- Маркер на карте

**Когда использовать:**
- Когда места очень мало
- В квадратных контейнерах
- Для брендинга без текста

**Пример использования:**
```blade
<img src="/assets/img/logo-icon.svg" alt="Ampleev.com" class="logo-icon">
```

### 4. **logo-dark.svg** (240×60px)
**Где использовать:**
- Темная тема сайта
- Темные секции страницы
- Ночной режим приложения
- Презентации с темным фоном

**Когда использовать:**
- На темном фоне (от #1e293b и темнее)
- В dark mode версии сайта

**Пример использования:**
```blade
<img src="/assets/img/logo-dark.svg" alt="Ampleev.com" class="logo-dark">
```

### 5. **favicon.svg** (32×32px)
**Где использовать:**
- Фавикон сайта (favicon.ico)
- Вкладка браузера
- Закладки браузера
- PWA иконка (вместе с другими размерами)

**Как использовать:**
- Для HTML фавикона:
  - Файл уже сохранен как `/blog/public/assets/img/favicon.svg`
  - В `layouts/app.blade.php` добавлен:
    ```html
    <link rel="icon" type="image/svg+xml" href="/assets/img/favicon.svg">
    ```
- Для генерации PNG фавиконов:
  - Используйте favicon.svg для создания PNG версий в размерах:
    - 16×16px
    - 32×32px
    - 48×48px
    - 180×180px (Apple touch icon)
    - 192×192px (Android)
    - 512×512px (Android/PWA)

## Технические требования

### Отступы
- Минимальный отступ вокруг логотипа: 16px со всех сторон
- Рекомендуемый отступ: 24px для комфортного восприятия

### Минимальные размеры
- logo-full.svg: не меньше 160px по ширине
- logo-compact.svg: не меньше 120px по ширине
- logo-icon.svg: не меньше 24px
- favicon.svg: не меньше 16px

### Фон
- Светлые логотипы (full, compact, icon): используйте на фоне светлее #94a3b8
- Темный логотип (dark): используйте на фоне темнее #334155

---

## Не рекомендуется

❌ Изменять пропорции логотипа  
❌ Менять цвета без согласования  
❌ Добавлять тени или эффекты (кроме hover-состояний)  
❌ Размещать на пестром фоне или поверх фотографий без подложки
