# Обновление контента маркетинговой страницы

**Дата создания:** 2026-01-07  
**Цель:** Убрать явные ассоциации с азартными играми для соответствия требованиям App Store

## Основные изменения терминологии

| Было | Стало | Примечание |
|------|-------|------------|
| дружеский покер | дружеская игра / настольная игра | Убрать упоминание "покер" |
| игроки | участники | Более нейтральный термин |
| докупки | пополнения | Убрать ассоциацию с покупкой фишек |
| проигрыши | баланс / результат | Убрать ассоциацию с проигрышем |
| выигрыши | результат / баланс | Убрать ассоциацию с выигрышем |
| чип-лидер | лидер по очкам | Убрать упоминание "чип" |

### Описание под заголовком

**Было:**
```
Подсчет очков и выигрышей нажатием одной кнопки

Вы, как организатор, можете запланировать игру, поделится с друзьями ссылкой для присоединения. Все игроки могут следить за очками в процессе игры, осуществлять докупки (каждый на своем телефоне или через организатора), завершать игру, просматривать итоги.
```

**Стало:**
```
Подсчет очков и результатов нажатием одной кнопки

Вы, как организатор, можете запланировать игру, поделиться с друзьями ссылкой для присоединения. Все участники могут следить за очками в процессе игры, осуществлять пополнения (каждый на своем телефоне или через организатора), завершать игру, просматривать итоги.
```

**Изменения:**
- "выигрышей" → "результатов"
- "игроки" → "участники"
- "докупки" → "пополнения"
- "поделится" → "поделиться" (исправление грамматики)

## Дополнительные рекомендации

### SEO и мета-теги
- Убедитесь, что в мета-описании и title страницы нет упоминаний "покер", "игроки", "докупки"
- Используйте: "счетчик очков", "настольные игры", "дружеские игры"

### Alt-тексты для изображений
- Проверьте alt-тексты всех изображений на странице
- Убедитесь, что в них нет упоминаний "покер", "фишки", "игроки"

### Call-to-Action кнопки
- "Установить из AppStore" - оставить как есть (нейтрально)
- "Доступно в AppStore" - оставить как есть (нейтрально)
