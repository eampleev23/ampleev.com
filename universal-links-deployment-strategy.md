## ❌ Что требует перевыпуска приложения

### 1. Universal Links (обязательно нужен перевыпуск)

**Почему:**
- Entitlements встроены в бинарный файл приложения при компиляции
- iOS проверяет `associated-domains` из бинарника, а не из App Store Connect
- Без перевыпуска Universal Links не будут работать

**Что не будет работать без перевыпуска:**
- ❌ Прямое открытие `https://pointscounter.ampleev.com/DY8TCY` в приложении
- ❌ Автоматическое открытие приложения после установки из App Store
- ❌ Universal Links вообще не будут работать

---

## ✅ Что можно сделать БЕЗ перевыпуска

### 1. Настроить файл `apple-app-site-association` на бэкенде

**Можно сделать прямо сейчас:**
- Создать файл `/.well-known/apple-app-site-association`
- Настроить правильный Content-Type (`application/json`)
- Добавить правильный Bundle ID и Team ID

**Зачем:**
- Когда выйдет новая версия, Universal Links сразу заработают
- Не нужно будет ждать настройки бэкенда после релиза

**Инструкция:** См. `universal-links-backend-checklist.md`

---

### 2. Обновить App Store URL в HTML странице редиректа

**Можно сделать прямо сейчас:**
- Найти HTML страницу, которая показывается при открытии `https://pointscounter.ampleev.com/{inviteCode}`
- Обновить ссылку на кнопке "Скачать Points Counter"
- Заменить на: `https://apps.apple.com/app/id6757125435`

**Зачем:**
- Сейчас при клике показывается "Не удалось подключиться"
- После обновления кнопка будет работать корректно

**Инструкция:** См. `universal-links-backend-checklist.md`

---

### 3. Custom URL Scheme уже работает

**Что работает сейчас (без перевыпуска):**
- ✅ Редирект на `pointscounter://activity/join/{code}` работает
- ✅ Если приложение установлено, оно откроется по Custom URL Scheme
- ✅ Присоединение к игре работает

**Ограничения Custom URL Scheme:**
- ⚠️ Показывается промежуточная страница "Открываем игру..."
- ⚠️ После установки из App Store приложение НЕ откроется автоматически
- ⚠️ Пользователь должен вручную открыть приложение
